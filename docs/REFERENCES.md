# References

These sources informed the threat model and protocol-shaped demo. They are not evidence that this prototype is certified or production ready.

- [x402 v2 core specification](https://github.com/x402-foundation/x402/blob/main/specs/x402-specification-v2.md) — payment requirements, payloads, and protocol scope.
- [x402 HTTP transport specification](https://github.com/x402-foundation/x402/blob/main/specs/transports-v2/http.md) — HTTP 402 challenge and payment headers.
- [Five Attacks on x402 Agentic Payment Protocol](https://arxiv.org/abs/2605.11781) — authorization, binding, replay, and web-layer attack research.
- [Free-Riding in the AI Economy: Demystifying Logic Flaws in x402-Enabled Payment Systems](https://arxiv.org/abs/2605.30998) — context binding and synchronization risks.
- [When HTTP 402 Meets the Blockchain: Risks on Emerging x402 Payments](https://arxiv.org/abs/2607.19545) — facilitator and server security analysis.
